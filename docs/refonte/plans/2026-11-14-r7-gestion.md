## Points de vigilance (Review Focus)

1. **Rail** : une page active dans un groupe replié ouvre ce groupe ; en changeant pour une page d'un autre groupe, le groupe retombe replié ; la préférence stockée n'est jamais réécrite par cette ouverture.
2. **Accord des compteurs** : 0, 1 et 2 donnent « 0 demande », « 1 demande », « 2 demandes » (jamais « (s) »).
3. **Documents, quatre cas distincts, un seul message affiché** : aucun document du tout, tous archivés (avec leur nombre), vue « Archivés » vide, filtres actifs.
4. **Temps** : le message nomme la période (« aujourd'hui », « cette semaine », « ce mois ») ; avec le filtre exact de Statistiques il le dit ; avec des filtres actifs il garde le bouton « Effacer les filtres ».
5. **Barre d'outils étroite** : elle passe à la ligne sans défilement horizontal et l'action principale reste visible.
6. **Facturation** : un élément avec facture rattachée reste « facturé » et verrouillé ; le bandeau Abby est toujours là ; `check-ux-v2-lot01b-abby-guard.cjs` reste à 25 contrôles.
7. **Documents, bouton unique** : « Bibliothèque et éditeur contractuels » ouvre la même fenêtre qu'avant ; plus aucune carte pour « Documents clients » ni pour « Autres documents » (ligne grisée).

  - `type TimePeriod = 'today' | 'week' | 'month'`.
  - `timeEmptyTexts(input: { period: TimePeriod; drilldown: boolean }): { empty: string; filtered: string }`. Sans filtre exact : `empty` = « Aucune session aujourd’hui.
