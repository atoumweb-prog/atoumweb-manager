# Roadmap V1 — AtoumWeb Manager

Cette roadmap sera détaillée après validation de l’architecture technique et du modèle de données.

## Phase 0 — Fondation

- Architecture technique
- Modèle de données
- Structure du dépôt
- Migrations de base
- Gestion des réglages
- Stratégie fichiers/sauvegardes
- CI et tests de base

## Phase 1 — Socle CRM

- Navigation principale
- Thèmes AtoumWeb / Noir / Blanc
- Recherche globale
- Journal d’activité
- Prospects
- Clients
- Annuaire

## Phase 2 — Commercial

- Offres & Tarifs
- Services / Offres versionnés
- Devis guidés
- Snapshots de devis
- Transformation devis → projet

## Phase 3 — Projets & production

- Projets
- Modèles de projet versionnés
- Lots / modules / tâches
- Fichiers & Ressources
- Bibliothèque projet
- Timer global
- Gestion des temps

## Phase 4 — Suivi opérationnel

- Demandes
- Interventions
- Maintenance
- Packs d’heures
- Sauvegardes

## Phase 5 — Gestion administrative

- Documents & Contrats
- Suivi facturation Abby
- Dépenses AtoumWeb
- Notifications / échéances

## Phase 6 — Bibliothèque AtoumWeb

- Catégories
- Visualisation code
- Fichiers/modules réutilisables
- Workflow d’adaptation depuis une Bibliothèque projet

## Phase 7 — Statistiques & finalisation

- Statistiques commerciales
- Rentabilité
- Statistiques temps/projets
- Revenus/dépenses récurrents
- Exports
- Vérification complète des parcours
- Stabilisation V1

## Règle de progression

Une phase peut commencer partiellement avant la précédente si les dépendances techniques sont stabilisées, mais `PROJECT_STATUS.md` reste la source de vérité pour l’avancement réel.
