## Portée codée

- Vue « **Vue organisée** » activée par défaut dans l’administration du Catalogue :
  1. Offres principales dans l’ordre Site vitrine, Site e-commerce, Site mariage, Maintenance WordPress ;
  2. autres Offres conservées, sans retrait ;
  3. Services complémentaires répartis par **catégorie principale existante** (libellé français, tri A–Z) et nom de prestation en A–Z français.
- **Maintenance WordPress** peut être un `item.type='service'` avec `commercialKind='subscription'` : priorité **visuelle uniquement**, aucune conversion artificielle en offre.
- Attribution aux quatre familles par **codes canoniques V1 connus** avec repli sur les intitulés lorsqu'un item n'a pas ces codes ; aucune écriture de code/famille/catégorie.
- Affichage état item, version et prix existants. Les éléments brouillon/inactifs/archivés restent visibles selon les **filtres d'administration** déjà existants.
- Bouton « **Tableau d'administration** » donnant accès à l'ancienne grille complète ; clic sur carte ouvre le même détail via `openItem` (garde UX-01 conservée).
- Styles limités à `catalog-overview*` et `catalog-view-switch` ; textes cibles >= 14 px, thèmes via variables CSS, mise en grille responsive.
- Tests Vitest ajoutés sur classification, tri, version/état, absence de doublon, non-mutation de la liste et fallback.
